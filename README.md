# RALLY Site

Public GitHub Pages website for RALLY, a premium indie mobile game where tennis is played through brick-breaker mechanics.

Live site: [https://gaborandi.github.io/rally-site/](https://gaborandi.github.io/rally-site/)

Useful links:

- Support: [https://gaborandi.github.io/rally-site/support/](https://gaborandi.github.io/rally-site/support/)
